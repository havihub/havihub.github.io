Code signing policy

La política de firma de código de Havi Hub. Última actualización: 18 de noviembre de 2026.

Estado actual: los archivos de Windows de Havi Hub todavía no tienen firma digital. El proyecto va a postular al programa gratuito de firma de código de SignPath Foundation para proyectos de código abierto. Cuando lo aprueben, esta página dirá desde qué versión vienen firmados.

Cuando la firma esté activa, esta página y cada versión dirán:

Free code signing provided by SignPath.io, certificate by SignPath Foundation

Qué se firma

Solo los archivos de Windows que se compilan desde el código público del repositorio havihub/HaviHub:

  • el instalador, HaviHub-<versión>-Setup.exe;
  • la versión portable, HaviHub-<versión>-portable.exe;
  • los ejecutables que van dentro de la carpeta comprimida, HaviHub-<versión>-win-x64.zip.

No se firman programas de terceros. Prism Launcher, el motor de juego que Havi Hub descarga la primera vez que se abre, viene de las versiones oficiales que publica el proyecto Prism Launcher en GitHub.

Cómo se compila y se firma

  1. Cada versión parte de una etiqueta del repositorio público, por ejemplo v1.0.0.
  2. GitHub Actions compila los archivos desde ese código, en máquinas de GitHub, y calcula la suma SHA-256 de cada uno.
  3. El aprobador revisa y aprueba a mano cada solicitud de firma antes de que SignPath la firme.
  4. La versión se publica en GitHub Releases, con las sumas SHA-256 en SHA256SUMS.txt.

Equipo y roles

Havi Hub lo mantiene una sola persona. Team roles and their members:

Autores y revisores (Committers and reviewers)
Havikun (@havikun)
Aprobadores (Approvers)
Havikun (@havikun)

Las cuentas con permiso para publicar versiones o aprobar firmas usan verificación en dos pasos.

Privacidad

Havi Hub no envía estadísticas ni datos de uso. Las conexiones que hace para funcionar, y lo que guarda en tu computador, están en la página de Privacidad. La conexión que no hace falta para usar el launcher (las redes de Havikun en Inicio) se explica la primera vez que se abre, con un enlace a esa página, y no ocurre antes de que la persona elija si se carga sola o solo al abrir cada red; también se puede cambiar después en Ajustes → Privacidad.

Comprobar una descarga

Compara la suma SHA-256 del archivo que descargaste con la que aparece en SHA256SUMS.txt, en la página de esa versión:

# Windows (PowerShell)
Get-FileHash .\HaviHub-1.0.0-Setup.exe -Algorithm SHA256

# Linux
sha256sum HaviHub-1.0.0-linux-x86_64.AppImage

Cuando la firma esté activa, también podrás ver el certificado en Windows: clic derecho en el archivo → Propiedades → Firmas digitales.

Desinstalar

  • Windows, con el instalador: en Configuración → Aplicaciones, busca Havi Hub y elige Desinstalar.
  • Windows, portable o ZIP: no se instalan, así que basta con borrar el archivo o la carpeta.
  • Linux, paquete .deb: sudo apt remove havihub
  • Linux, AppImage: si activaste «Mostrar Havi Hub en mi menú de aplicaciones» en Ajustes, desactívalo primero y luego borra el archivo. Si usaste «Instalar para todos», borra también la copia que quedó en el sistema:
sudo rm /opt/havihub/HaviHub.AppImage /usr/share/applications/havihub.desktop /usr/share/icons/hicolor/512x512/apps/havihub.png
sudo rmdir /opt/havihub

Tus perfiles y cuentas quedan en la carpeta de datos; la página de Privacidad explica cómo borrarlos.

Reportar un problema

Si encuentras un archivo firmado a nombre de Havi Hub que no salió de este repositorio, o cualquier otro problema con las descargas, avísame en GitHub.

Code signing policy

Last updated: November 18, 2026.

Current status: Havi Hub's Windows files are not code-signed yet. The project is going to apply to the SignPath Foundation's free code signing program for open-source projects. Once it is approved, this page will say from which version on the files are signed.

Once signing is active, this page and every release will say:

Free code signing provided by SignPath.io, certificate by SignPath Foundation

What gets signed

Only the Windows files built from the public source code in the havihub/HaviHub repository:

  • the installer, HaviHub-<version>-Setup.exe;
  • the portable version, HaviHub-<version>-portable.exe;
  • the executables inside the compressed folder, HaviHub-<version>-win-x64.zip.

No third-party programs are signed. Prism Launcher, the game engine that Havi Hub downloads the first time it opens, comes from the official releases that the Prism Launcher project publishes on GitHub.

How it is built and signed

  1. Every release starts from a tag in the public repository, such as v1.0.0.
  2. GitHub Actions builds the files from that code, on GitHub's machines, and computes the SHA-256 checksum of each one.
  3. The approver reviews and manually approves every signing request before SignPath signs it.
  4. The release is published on GitHub Releases, with the SHA-256 checksums in SHA256SUMS.txt.

Privacy

Havi Hub sends no statistics or usage data. The connections it makes to work, and what it stores on your computer, are listed on the Privacy page. The one connection the launcher does not need in order to work (Havikun's social media on the Home page) is explained the first time the app opens, with a link to that page, and it does not happen before the person chooses whether it loads on its own or only when a channel is opened; it can also be changed later in Settings → Privacy.

Checking a download

Compare the SHA-256 checksum of the file you downloaded with the one in SHA256SUMS.txt, on that release's page:

# Windows (PowerShell)
Get-FileHash .\HaviHub-1.0.0-Setup.exe -Algorithm SHA256

# Linux
sha256sum HaviHub-1.0.0-linux-x86_64.AppImage

Once signing is active, you will also be able to see the certificate on Windows: right-click the file → Properties → Digital Signatures.

Uninstalling

  • Windows, installed with the installer: in Settings → Apps, find Havi Hub and choose Uninstall.
  • Windows, portable or ZIP: they are not installed, so deleting the file or the folder is enough.
  • Linux, .deb package: sudo apt remove havihub
  • Linux, AppImage: if you turned on “Show Havi Hub in my applications menu” in Settings, turn it off first and then delete the file. If you used “Install for everyone”, also delete the copy left on the system:
sudo rm /opt/havihub/HaviHub.AppImage /usr/share/applications/havihub.desktop /usr/share/icons/hicolor/512x512/apps/havihub.png
sudo rmdir /opt/havihub

Your profiles and accounts stay in the data folder; the Privacy page explains how to delete them.

Reporting a problem

If you find a file signed in Havi Hub's name that did not come from this repository, or any other problem with the downloads, let me know on GitHub.
